# 网页环与页脚那扇小门

<!-- DESC SEP -->

从 1994 年手拉手串联网页讲起，聊聊 Webring 如何让独立网站首尾相接，顺便在页脚放好通往 Geekring 那扇小门。

<!-- DESC SEP -->

如今上网找东西，大多先往搜索框里敲几个词，或者等推荐流把卡片推到眼前。各家个人博客散在海面上，各自守着一座孤岛，彼此互不往来。访客顺着搜索链接漂过来，读完一篇，关掉标签页也就离开。

最近我接触到 [Webring](https://en.wikipedia.org/wiki/Webring)（网页环）。

它把网站串在一起，做法非常朴素。几十家甚至几百家个人网站气味相投，彼此用链接手拉手围成一圈。每家站点都在页面角落挂上一小截导航条，上面摆着「上一站」「随机」「下一站」三个入口。

你在这一家读完文章，点一下「下一站」，就直接跨进邻居院子。要是顺着同一个方向一直点下去，逛完一整圈，最终还会回到出发时那张页面。

## 从手写链表到中心脚本

[Webring World](https://www.webringworld.org) 建站于 2002 年 11 月，由一群资深环主（Ringmaster）共同打理，站内那篇[网页环简史](https://www.webringworld.org/history-of-webrings/)把这套机制怎么诞生、怎么演变记述得很完整。

1994 年 12 月，伦敦帝国理工学院 Denis Howe 发起一项实验，取名 EUROPa（Expanding Unidirectional Ring Of Pages，单向扩展网页环）。他好奇一条超链接链条究竟能在万维网上延伸多远。

最初全靠手工维系。每家网站都在页面上放一个链接，直接指向下一家站点。每当有新成员加入或者旧成员退出，相邻站长就互发邮件，打开 HTML 文件手改地址。

整圈网站就像一条手写单向链表。只要中途某台服务器断电停机，或者某位站长出门度假忘改链接，圆环就会当场断开。

1995 年，十七岁少年 Sage Weil 写下一段 Perl [CGI](https://en.wikipedia.org/wiki/Common_Gateway_Interface) 脚本，随后创办 WebRing。他把名单收进中心服务器，交由脚本统一保管并处理跳转。

各家站长只需往网页里贴一小段固定代码，不必再操心左右邻居是谁。访客点击「下一站」或「随机」，请求先发往中心脚本，再由脚本按名册序号把人送去目标站点；要是撞上某家站点暂时离线，还能顺手跳过（Skip）。

短短几年间，WebRing 聚起七万多个圆环，主题各异，一共串起一百五十万家网站。

再往后便是世纪末互联网并购潮。WebRing 先卖给 Starseed，接着并入 GeoCities，最终被雅虎收入囊中。商业巨头急着变现，先是强行塞入广告，随后又撤掉各环原有目录页，哪怕环主精心排过版也一并抹去，统一换成雅虎自家门户页。

2000 年夏天，「语录环」（The Quotation Ring）环主 Gunnar Hjalmarsson 决定自谋出路。他原本不算程序员，平时只改过留言板脚本。那年夏天刚好阴雨连绵，他耗时一整个暑假边查资料边学 Perl，在 7 月底从头写出开源程序 Ringlink。自那以后，谁都可以在私人服务器上架起一只小环，无需再看大型门户脸色。

## 不在搜索引擎第一页

后来搜索引擎与社交时间线接管互联网入口，Webring 渐渐退回暗处，却一直有人接力维护。近几年不少独立创作者厌倦算法投喂，又开始重新搭起这种小环。

[Geekring](https://geekring.net/) 便是其中一处聚集地，面向个人网站、技术玩家与 Geek 文化爱好者。

点开 Geekring 首页，扑面而来一股 1993 年手写网页气息，正中摆着一段宣言，语气直白。

> This is the old web, in 2024! For all those funny, quirky, interesting, personal, strange, offbeat websites that's not page 1 on the search engines.

大意是说，这里属于旧互联网。有些网站有趣、古怪、个人化、与众不同，而且不会出现在搜索引擎首页，这里就欢迎它们。

站长 DusteD 在[建站故事](https://geekring.net/why.html)里聊起过缘由。十三岁那年，他找来一台奔腾 100MHz、32MB 内存电脑，装上 Windows 95 与 Apache，塞进当地青年俱乐部壁橱，借着网吧线缆架起自己第一台网站服务器。

2019 年某天在办公室上班时，他接到电话，得知父亲确诊癌症。他没法再待下去，提前开车回家。握着方向盘走在路上，两种念头同时涌上来，既想一个人躲进安静角落，又渴望和世上其他人保持一点联结。他想在网上种一小片花园，慢吞吞亲手打理，永远不必追求规模扩张。

回到家，他在脑海里理清逻辑，坐下来写完程序，接进 Nginx，往后多年几乎没再改动。

这只圆环脾气非常鲜明。它只收非商业站点，只要网站奔着卖货赚钱去，一律拒之门外；个人主页、折腾笔记与自由开源软件项目全都欢迎。

所有成员名单就躺在一份纯文本文件 [`/list.txt`](https://geekring.net/list.txt) 里，全凭手工维护。每家站点领到一个编号，借着 `previous`、`random` 与 `next` 三条路径彼此串连。随机跳转还留有一点偏心，哪家站点平时被抽中次数少，下一次就更容易被随机抽中，送到访客眼前。

考虑有些极客还在用古董电脑冲浪，那些老硬件跑不动现代加密算法，Geekring 默认同时提供明文 HTTP 与 HTTPS。站上不设 Cookie，不挂客户端脚本，服务器也不记访问日志。

连入环审核也慢悠悠。DusteD 在页面上写明，自己只在心血来潮时查看待审名单，也许隔上一两天，也许等上好几周，去留全看当天心情。

## 页脚处那扇小门

用搜索引擎找东西，人总得先想好一个明确问题，再去翻找答案。

Webring 却把偶遇留给浏览器。你原本只是读完一篇技术排障笔记，顺手点一下页脚处 `Random` 或 `Next`，下一秒就可能闯进某位陌生人家里，看他拆解古董合成器，或者翻看一份手绘像素画集。

没有搜索排名催促，也没有推荐算法揣测喜好，网站与网站只靠站长之间一点相近脾气彼此认领。

前两天，我也往「无垠」中英文页脚添上一枚 [Geekring](https://geekring.net/) 链接，顺着表单递交加入申请。

申请眼下还静静躺在待审队列里，等远方那位环主哪天心情不错、打开后台检阅。等领到环上序号，页脚处就会多出「上一站」「随机」「下一站」三扇小门。到那时，谁读完文章想继续闲逛，随时可以推门去隔壁坐坐。
